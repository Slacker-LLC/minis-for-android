# 本地化（i18n）

> 本文说明界面文案放在哪里、改的时候要遵守什么、怎么复跑审计。当前覆盖数字是 2026-09-20 的快照，
> 复跑 `python3 scripts/audit_strings.py` 即可得到最新结果。

## 语言与真源

| 目录 | 语言 | 条目 | 相对默认缺失 |
|---|---|---|---|
| `values/` | 英文（默认真源） | 2297 | — |
| `values-zh/` | 简体中文 | 2297 | 0 |
| `values-zh-rTW/` | 繁體中文（台灣） | 2297 | 0 |
| `values-ja/` | 日本語 | 1760 | 537 |
| `values-ko/` | 한국어 | 1752 | 545 |
| `values-de/` | Deutsch | 1752 | 545 |
| `values-fr/` | Français | 1644 | 653 |
| `values-ru/` | Русский | 2042 | 255 |

`values/` 是唯一真源：其它语言必须与它同 key 集合；缺 key 会在运行时回退英文（Android 行为），
因此在补齐之前，缺失条数就等于「这些语言下会看到英文的条数」。

字符串分散在 `src/android/app/src/main/res/values*/` 下的多个文件（`strings.xml`、
`strings_session_advanced.xml`、`bot_strings.xml`、`strings_backup.xml`、
`restricted_settings_strings.xml`）——新增 key 时要放进与默认语言相同的文件，放错文件会让审计脚本报错。

## 硬规则

1. **新文案一律进资源，8 语言同步**：默认英文 + zh / zh-rTW / ja / ko / de / fr / ru。
2. **界面之外的不进资源**：模型侧提示词正文（人格、系统提示词）、guest CLI 的命令输出与帮助文本、
   日志、测试夹具、数据表——它们不是用户界面文案，翻译反而会改变模型输入。
3. **品牌与协议名原样保留**：Minis、Shizuku、MCP、HTTP、SSE、STDIO、JSON、Token、URL、
   Markdown、OAuth、GitHub、Claude Desktop、Responses API、Chat Completions、Azure OpenAI 等。
4. **slash 命令 token 不翻译**：`/model`、`/permission`、`/goal`、`/plan` 是插入到输入框的命令名，
   只有它的副标题走资源。
5. **术语一致**：session=会话、provider=提供商、skill=技能、module=模块、accent=强调色、
   work process=工作过程、subagent=子代理、scheduled task=定时任务、agent 保留英文 Agent。

## 已知的坑

- **撇号与引号**：Android 资源里 `'` 要写成 `\'`、`"` 写成 `\"`，否则 AAPT2 报
  `unescaped apostrophe` / 资源编译失败。
- **二次转义**：从已转义的资源文本重新生成另一种语言时，不要用解析后的值再转义一遍，否则 `\'` 会变成
  `\\'`；简体→繁體这类批量转换应基于**原始资源文本**（见 2026-09-19 的记录）。
- **复数**：俄语必须有 `many`（`one/few/many/other`），否则 lint 报 `MissingQuantity`；
  中文、日文、韩文只有 `other`，缺 `one` 是正常的。
- **格式占位符**：`%1$s` / `%1$d` 在翻译里必须保留；调用处传参但资源里没有占位符会被 lint 判为
  `StringFormatInvalid`（本轮就抓到过一次）。
- **Gradle 串行**：本机多个 worktree 共享 KSP 缓存，构建统一用
  `flock /tmp/minis-gradle.lock ./gradlew … --no-daemon --max-workers=1`。

## 审计工具

```bash
# 从仓库根运行；不给 --out 时报告写到临时目录并打印路径
python3 scripts/audit_strings.py
python3 scripts/audit_strings.py --out /tmp/i18n-report
```

输出九类清单（TSV）+ `summary.txt`：

| 文件 | 内容 |
|---|---|
| `A_same_as_english.tsv` | 与英文默认值完全相同的 key（逐语言） |
| `B_missing_in_locale.tsv` | 该语言缺失、会回退英文的 key |
| `C_orphan_keys.tsv` | 只存在于某语言、默认里没有的 key |
| `D_plural_gap.tsv` | 复数的数量缺口 |
| `E_format_mismatch.tsv` | 格式参数与默认不一致 |
| `F1_kotlin_cjk.tsv` | Kotlin 里的中文字面量（文件:行 + 作用域 + 是否 UI 上下文） |
| `F2_kotlin_ui_english.tsv` | Kotlin 里 UI 上下文的英文字面量 |
| `F3_kotlin_prose_candidates.tsv` | 其它英文散文候选（人工判断用） |
| `G_xml_hardcoded.tsv` | 非 `values*` XML 里的硬编码文本 |

判断「该翻还是该留」时，以 `A_same_as_english.tsv` 为线索人工过一遍：品牌/协议/纯占位符保留，
其余翻译。
