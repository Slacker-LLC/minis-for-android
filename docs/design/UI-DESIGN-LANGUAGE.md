# UI 设计语言：纯白 iOS 风格（目标规范）

状态：**目标规范，分步落地中**。本文定义视觉与交互的长期边界；每个令牌/规则的「现状」列描述
落地前后的代码事实，最终以源码与测试为准。落地进度见文末「实现状态」。

设计稿在 Design 画板中维护（182 块，覆盖全部页面、弹窗与小详情页）；本文是从画板提炼、可对照
Compose 代码的文字版规则，不重复画板内容。

## 1. 目标

- 视觉：iOS 17/18 时代的纯白、克制、高级感；不追求 iOS 26 的液态玻璃。
- 统一：整个 App 只有一种白、一种灰、一种强调色；所有操作是文字按钮。
- 结构：会话列表是**左侧抽屉**，不是整页；功能入口按使用频率与归属重新摆放。
- 不改变：产品身份、Runtime、存储与安全合同（见 `docs/contracts/`）。本文只约束 UI 层。

## 2. 原则

1. **一种白**：页面底色纯白；卡片也是白色，只靠 0.5dp 发丝线与页面区分，不再使用米白/浅灰卡片。
2. **一种灰**：控件填充、气泡、图块、输入框统一 `#F2F2F7`（深色 `#2C2C2E`）。不得再引入第二种灰。
3. **一种强调色**：强调色就是文字按钮的标签色，因此默认强调色和用户可选的每一种强调色，在白底与
   `#F2F2F7` 上都必须满足 WCAG AA（≥ 4.5:1）。浅色版为此在保持色相的前提下加深（黄、橙会明显偏暗，
   这是可读性的代价）；`UiDesignTokensTest` 逐个校验。
4. **文字按钮**：所有「动作」用文字按钮表达，见第 6 节。
5. **弹层压在真实页面上**：菜单、对话框、sheet 出现时，背后必须是它所属的真实页面（画板与截图测试
   都按此验收），不能是空白占位。
6. **信息密度优先于装饰**：不加无信息的插画、渐变、投影；层次靠留白、发丝线与字重。

## 3. 颜色令牌

| 令牌 | 浅色 | 深色 | 用途 | Compose 位置 |
|---|---|---|---|---|
| page | `#FFFFFF` | `#000000` | 页面底色 | `NeutralGroupedBg` / `minisPageBackground()` |
| card | `#FFFFFF` + 0.5dp hairline | `#1C1C1E` + hairline | 分组卡片 | `SectionDesign.cardColor()` / `cardBorder()` / `Modifier.groupedCard()` |
| fill | `#F2F2F7` | 沿用 T153 提亮值（`#26262A` 等） | 输入框、气泡、图块、分段控件底 | `ChatPalette.secondaryBg` / `toolBg` |
| hairline | `#E5E5EA` | `#38383A` | 分隔线、卡片描边 | `NeutralOutline` |
| sheet | `#FFFFFF` 不透明 | `#1C1C1E` 不透明 | sheet / 对话框（菜单见下） | `minisSheetColor()` + 弹层组件 |
| bar | 白 72% + 模糊 | 黑 72% + 模糊 | 顶栏/底栏（玻璃） | `GlassKit` |
| scrim | 黑 18% | 黑 55% | 弹层遮罩 | 各弹层组件 |
| accent | `#0068D6` | `#0A84FF` | 文字按钮、开关、选中态 | `TealPrimary`（名字保留，值变更） |
| fg | `#000000` | `#FFFFFF` | 主文字 | `onBackground` |
| fg2 | `#636369` | `#98989F` | 次要文字 | `ChatPalette.secondaryText` |
| ok / warn / bad | `#1F7A36` / `#A65100` / `#D70015` | `#30D158` / `#FF9F0A` / `#FF453A` | 状态文字与图标 | `ChatColors.ok/warn/bad`；`colorScheme.error` 与 `bad` 同值 |

深色列中 fg2、ok/warn/bad 采用 iOS 系统深色色值作为起点，画板未逐项固定。深色 fill 沿用代码里
T153 有意提亮的一组值（`#26262A`/`#2C2C30`/`#3A3A3F`），不回退成 iOS 原值；注意 `#0A84FF` 落在
`#26262A` 上只有 4.13:1，所以深色下文字按钮应放在页面/sheet/卡片表面，不要放在 fill 上。
设计稿里的 ok 绿 `#248A3D` 在白底只有 4.40:1，未达 AA，已改为 `#1F7A36`（5.39:1）。

**卡片与 fill 的分工**：卡片是白底 + 发丝线（深色 `#1C1C1E` + 发丝线），由 `SectionDesign` 的
`cardColor()` / `cardBorder()` / `groupedCard()` 提供，设置页、挂载/共享文件夹页、模型选择器等分组卡片都走它。
`surfaceContainer*` 体系保持为 fill 灰（`#F2F2F7`），只给输入框、气泡、图块、代码块用，不再当卡片色。
深色菜单（`MinisMenu`）刻意保留抬升的 `#2C2C2E`，因为它常叠在 `#1C1C1E` 的 sheet 上，同色会失去层次。

**分类标识色例外**：设置分类、会话分类、备份分类、工具类型等「图标标识色」（iOS 系统色板）不属于状态色，
不受 ok/warn/bad 约束；其中处于非 Compose 上下文的映射函数保持原字面值，Compose 内的
`#34C759` / `#FF9500` / `#FF9F0A` / `#FF3B30` 已统一改为 `ok` / `warn` / `bad`。终端配色有独立调色板，不在此列。

对比度（相对 `#FFFFFF`，已按 WCAG 相对亮度公式计算）：

| 前景 | 对比度 | 结论 |
|---|---|---|
| 旧 accent `#528AD2` | 3.54:1 | 不满足 AA 正文 |
| 新 accent `#0068D6` | 5.31:1 | 满足 |
| fg2 `#636369` | 5.97:1 | 满足 |
| 旧 secondaryText（60% 透明度 `#3C3C43`） | 3.44:1 | 不满足，改为实色 fg2 |
| 旧深色 accent `#6A94CE`（黑底） | 6.74:1 | 满足；深色不做变更，仅统一为 `#0A84FF` 时复算 |

约束：

- 深色调色板在 T153 中被有意提亮，落地时不得回退可读性；变更深色值必须复算对比度。
- 禁止在业务代码里写死 `Color(0xFF…)` 表示表面色（页面/卡片/弹层/灰）：卡片用 `SectionDesign.cardColor()`，
  弹层用 `minisSheetColor()`，灰用 `surfaceContainer*`（fill）。状态色用 `ChatColors.ok/warn/bad`。
- 代码块与终端跟随主题：浅色为 fill 底 + 黑色文字；深色沿用深灰底（`#262626`）+ 浅绿文字；不再固定
  黑底绿字。聊天里的代码块已按此调整；终端页仍是固定深色，属于步骤 5。
- 米色 `fabAccent` 去除，改用 accent。

## 4. 形状、尺寸、字体

| 项 | 规则 |
|---|---|
| 卡片圆角 | 12dp（分组卡片）；输入框/气泡沿用现有 |
| Sheet 圆角 | 顶部 28dp（`MinisShapes.extraLarge`） |
| 对话框圆角 | 14dp，宽度 270–320dp（iOS 警示框比例） |
| 最小点击区 | 48dp（按钮行高与现有 `MinisButtonHeight` 一致），紧凑场景 32dp（`MinisSmallButtonHeight`） |
| 页面边距 | 16dp |
| 抽屉宽度 | `min(300dp, 屏宽 × 0.84)`，右侧至少露出 16% |
| 字体 | 系统字体；正文 16sp，次要 13–14sp，页面大标题 28sp/粗体，导航标题 17sp/半粗；跟随系统字号缩放 |

## 5. 表面层级

从下到上：

1. **page**：纯白。
2. **card**：白 + 发丝线（分组内容）。
3. **fill**：`#F2F2F7`（控件、气泡、图块）。
4. **bar**：顶/底栏，玻璃（白 72% + 模糊）。API 36+ 或无法模糊时退化为不透明白 + 发丝线（沿用
   `GlassKit` 现有降级行为）。
5. **overlay**：scrim + 不透明白 sheet/对话框/菜单。**弹层本身不做模糊**，避免与 bar 玻璃叠加变灰。

## 6. 按钮系统

规则：**所有动作都是文字按钮**。

| 语义 | 样式 |
|---|---|
| 普通 | accent 蓝色文字，常规字重 |
| 主要 | accent 蓝色文字，**半粗（SemiBold）**；同一页面/弹层最多一个 |
| 破坏性 | `bad` 红色文字（`destructive = true`，可与主要同时半粗） |
| 禁用 | fg2 文字，40% 透明度 |

不属于「文字按钮」规则的例外（它们不是动作按钮或本身有 iOS 通用形态）：

- 仅图标的按钮：发送、停止、录音、返回、更多（⋯）；
- 开关、分段控件、滑块、输入框；
- 系统对话框（警示框/菜单/操作面板）内的选项按钮，按 iOS 形态排布，但同样是文字；
- 芯片（filter chip）作为筛选状态，不是动作。

禁止：

- 实心/胶囊/描边/淡色底按钮；
- 直接使用 `Button`、`OutlinedButton`、`FilledTonalButton`（`MinisButton.kt` 之外）；
- 一个页面出现两个以上半粗主要按钮。

实现：`MinisButton` 系列保留函数名（避免调用点大面积改名），其中「实心」和「描边」变体渲染为文字
样式，并去掉 `colors`/`shape`/`border`/`elevation` 参数，只保留 `destructive`；`MinisButtonUsageGuardTest`
扫描源码，禁止在 `MinisButton.kt` 以外出现原生 `Button`/`OutlinedButton`/`FilledTonalButton`/
`ElevatedButton`（View 体系的 `android.widget.Button(context)` 除外）。

## 7. 弹层规范

| 类型 | 规则 |
|---|---|
| 警示框 Alert | 居中，白色不透明，圆角 14dp；标题 + 可选一行说明；按钮横排（≤2）或竖排（≥3），按钮间发丝线；破坏性红色；取消在左/上 |
| 确认（危险操作） | 同 Alert，明确写出后果；不可撤销操作必须红色确认按钮 |
| Sheet | 底部，白色不透明，顶部圆角 28dp，顶部抓手；标题栏文字按钮：左「取消」，右「完成」（粗体） |
| 操作面板 Action sheet | 底部，选项文字居中，取消项独立成组 |
| 上下文菜单 | 锚点弹出，白色，圆角 12dp，每行一个文字项，破坏性置底且红色 |
| Toast / Snackbar | 白色 + 发丝线，文字单行；带动作时动作为 accent 文字 |
| Banner | 页面内，fill 底，图标 + 文字 + 文字按钮 |
| 遮罩 | 浅色黑 18%，深色黑 55%；点击遮罩关闭（破坏性确认不因点遮罩关闭，需明确取消） |

实现：新增/保留的对话框统一走 `MinisAlertDialog`；直接使用 `AlertDialog` 的地方（当前约 77 处）
逐步迁移，`ModalBottomSheet`（约 125 处）通过统一外壳应用 sheet 令牌。

## 8. 会话抽屉

- 从**左侧**滑出，宽度见第 4 节；右侧露出聊天页的一小条。
- 点击露出的那条（遮罩）、或向左滑动、或系统返回键，都会关闭抽屉（`ModalNavigationDrawer` 行为，
  遮罩色用 `minisOverlayScrim`）。
- 内容自上而下：标题行（搜索图标、「编辑」文字按钮）→ 搜索框（点搜索图标展开）→ 新建聊天（纯强调色文字行）
  → 功能入口（Bot、定时任务、终端、文件）→ 置顶 → 分组 → 最近 → 设置。
- 会话长按菜单：重命名、置顶/取消置顶、移到分组、选择、删除（红色，需确认）。
- 分组行：点击展开/折叠（沿用手风琴语义），长按菜单：组内新聊天、置顶、重命名、解散、删除分组及会话。
- 「编辑」进入多选：顶部变为「取消 / 已选 N / 移动 / 删除」文字按钮；「移动」打开现有分组选择器，
  「删除」先确认。
- 分组、置顶、多选、分组选择器、分组的重命名/解散/删除对话框都复用 `SessionListViewModel` 与
  `FolderActionDialogs`，抽屉不另存一份状态。搜索中显示平铺结果，不显示分组。
- 不再有「会话列表整页」作为主入口（旧路由保留兼容，见第 9 节）。

## 9. 信息架构调整（旧 → 新）

| 旧 | 新 | 说明 |
|---|---|---|
| 存储、共享文件夹、挂载文件夹、备份分散在「运行时与存储」 | 这些是「文件」入口的内容，不在设置里；抽屉的「文件」入口打开它（重做前暂由隐藏的 `SettingsCategory.FILES` 页承载） | 旧路由（`STORAGE`、`SHARED_FOLDERS`、`MOUNTED_FOLDERS`、`BACKUP`）全部保留，只是入口位置变了；「备份与恢复」同时出现在「数据与关于」 |
| 会话设置分散：会话配置面板 + 菜单里的「Token 用量」+ 一个无入口的「会话信息」面板（自动压缩、快速模式） | 合并进同一个「会话配置」面板；菜单里独立的「Token 用量」项移除，`SessionInfoSheet` 删除 | 自动压缩与快速模式此前在聊天界面里没有入口，合并后可达 |

| 终端固定深色 | 跟随主题 | 见第 3 节代码块规则 |
| 会话列表整页 | 左侧抽屉 | 见第 8 节 |
| 虚拟屏幕（V1–V4，实验性） | 入口归入设置「系统与权限」，紧邻「Root」行；「运行环境」只放 Rootfs、环境变量与终端/文件入口 | 它依赖 Root 授权（libsu root 服务），属于设备能力授权，不是 chroot 运行时；定时任务的权限档位在定时任务编辑页 |

注意：IA 调整只移动入口与页面组织，**不改变**任何 Runtime、权限或存储行为。涉及 Root、共享目录、
挂载的页面只调整位置，权限确认流程保持原样。画板里「会话文件」并入文件中心：会话文件页面
（`SessionStorageDetailScreen` 的 Session Files）本来就存在，入口是「设置 → 文件 → 存储 → 会话」，
已经在「文件」入口下，无需再加一行；聊天菜单里的「聊天文件」入口保留（它按当前会话打开）。

## 11. 验收标准

1. 默认强调色与 fg2 在白底上对比度 ≥ 4.5:1（脚本或单测可复算）。
2. 浅色主题下，页面/卡片/弹层背景只出现纯白；灰色只出现 `#F2F2F7`（fill）与发丝线。
3. 源码中 `MinisButton.kt` 以外没有原生 `Button`/`OutlinedButton`/`FilledTonalButton`（测试守卫）。
4. 任一页面无实心/胶囊/描边按钮；同页半粗主要按钮 ≤ 1（当前由 `MinisButton` 一律渲染为半粗，
   同页多个 `MinisButton` 的页面需要逐页人工复核，尚未审计）。
5. 抽屉：点击露出条、左滑、返回键均能关闭；分组与多选可用。
6. 新增字符串覆盖全部 8 个语言目录，`scripts/audit_strings.py` 通过（见 `docs/I18N.md`）。
7. 深色主题可读性不回退（关键页面对比度复算）。
8. 安全类改动（本文范围内基本没有）若出现，必须带拒绝/越界用例。

## 12. 不在范围内

- iOS 26 液态玻璃；
- 桌面/平板分栏布局的重新设计（保持现有 `ChatSplitScaffold` 行为）；
- Runtime、Root、网络代理、存储与 MCP 行为；
- `com.openminis.app` 命名空间与 `applicationId` 的任何迁移；
- 真机上的模糊效果：API 36+/模拟器上模糊本就降级，**真机 OEM 表现未验证**。
