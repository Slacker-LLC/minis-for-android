# 设置信息架构审计（重复与重叠）

用户反馈：设置里有很多重复的东西，不只是界面。这份文档记录 2026-10-01 对设置页面树做的核对：哪些已经合并/删除，哪些仍有重叠、需要决定怎么合。**已做的项以代码为准**，“待决定”是没有动的。

## 已处理

| 重复 | 处理 |
|---|---|
| 模型首页的「思考规则」列表页与各服务商详情里的思考规则重复 | 删除入口和列表页；规则只在服务商详情里编辑（设计稿有这一项，按用户要求删） |
| 运行环境页的「终端」「浏览文件」与会话抽屉里的终端、文件重复 | 运行环境页只留 Rootfs 与环境变量 |
| 文件页「高级」里的「浏览整个 Rootfs」与 Rootfs 管理页自带的「浏览文件」重复；「在终端中打开」与抽屉的终端重复 | 删除「高级」整段 |
| 「工具权限」页与「系统授权」页各有一段相同的「无障碍受限」处理 | 只留在系统授权页 |
| 系统与权限下各子页的大段说明文字（系统增强的两份能力清单、特权后端与系统授权的各段页脚、后台与通知的页脚） | 去掉，只保留一行标题/副标题；状态异常时才出现的一行提示保留 |

## 仍保留的两个入口

团队、定时任务在 Agent 分类和会话抽屉各有一个入口（打开的是同一个页面）。这是用户之前明确要求的（设置里应涵盖所有设置项），不改。
