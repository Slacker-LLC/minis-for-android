# 备份与恢复：包含什么、不包含什么

备份包是 `.minisbak`（zip），可加密。默认存到手机的 `Download/Minis Backups`，也可以同时送到 SMB / WebDAV / SFTP / S3 / FTP 服务器。入口在 设置 → 文件管理 → 备份与恢复。

## 包含

| 类别 | 内容 |
|---|---|
| 聊天 `chats` | 会话、消息、压缩标记、文件夹、会话工作区文件；**角色卡**（卡片、头像、角色记忆）和**机器人**定义 |
| 共享文件 `shared_files` | `/var/minis/shared` |
| 技能 `skills` | 已安装的技能 |
| 记忆 `memory` | 记忆文件 |
| MCP 服务器 `mcp_servers` | MCP 配置 |
| 服务商 `providers` | 服务商与模型配置、自定义思考规则、**子代理**、凭证（API Key、OAuth 令牌）；以及**设置**：下表的偏好、自定义系统提示词与模块改动、定时任务 |
| 环境变量 `environment_variables` | 变量与值 |

随「服务商」一起备份的偏好（`data/app_settings.json`），只有这些，且按文件名加键名白名单：外观（主题、强调色、界面风格、字号、语言、启动会话、回车键行为、保持亮屏、工具预览等）、平板列表栏、输入框模式、Codex 快速模式、自动压缩、步骤展示、全局记忆开关、默认智能体预设、浏览器空闲超时与视口、文件浏览显示隐藏文件、朗读（开关、静音、语速、系统音色）、语音识别语言、镜像选择，以及各提示词模块的启用开关。

## 不包含

- **权限与授权**：无障碍/Root/无人值守/离线工具权限、会话权限、审批记录。恢复后需要重新授权，这是有意的：备份包不能成为授权的途径。
- 设备状态与缓存：设备标识、安装与 rootfs 状态、系统音色之外的语音引擎、桌面图标选择、崩溃与卡顿记录、模型规则缓存、更新下载。
- 备份目的地（服务器）的配置与密码：恢复后重新添加。
- 外部文件夹挂载（系统授予的目录权限无法跨安装迁移）。
- Web 应用快捷方式（依赖桌面上的固定项，卸载即消失）、机器人的委派/任务/收件箱流水、宠物素材、通知历史、日志。
- Ubuntu 环境里自己装的软件和 home 目录里的文件（只备份会话工作区与共享文件）。

## 恢复时的规则

- 同一个 id 已经存在时，**只有更新的一方生效**（以 `updatedAt` 为准）；本机更新过的内容不会被旧备份覆盖。
- **完整权限的定时任务会以关闭状态恢复**：授予完整权限需要用户在编辑器里确认，备份包不能绕过它。只读任务正常恢复。
- 偏好、提示词、角色、机器人、任务都会校验：不在白名单的偏好、类型不对的值、未知的提示词模块、不安全的 id、读不了的角色卡会被忽略，并计入「已忽略」。
- 偏好里有一部分只在启动时读取，恢复后需要**重启应用**才完全生效。
- 加密包需要口令；被改动过的成员会在完整性校验处被拦下。

## 换签名（卸载重装）的步骤

1. 先装带「本机」备份的版本（与手机上现有版本同一签名，直接覆盖，不丢数据）。
2. 备份与恢复 → 开始备份。完成后文件在 `Download/Minis Backups`，用系统文件管理器确认它在，并复制一份到别处更稳妥。
3. 卸载旧版，装新签名的版本。
4. 备份与恢复 → 恢复 → 选择文件，选 `Download/Minis Backups` 里的 `.minisbak`。输入口令（如果加过密），确认类别。
5. 重启应用；到「定时任务」里确认并重新开启需要完整权限的任务；重新授予无障碍/Root 等权限；重新添加备份服务器。
