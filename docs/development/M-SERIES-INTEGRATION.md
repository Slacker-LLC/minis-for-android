## 输入、恢复与去重

Room v26 只给既有 `messages` 增加 nullable 请求状态、投递方式、Task/停止代次、Run 和用户输入标记。旧消息值为 null，历史正文保持原有含义，没有新增独立邮箱或消息日志。

输入先准备并保存正文、粘贴资料和附件，再确认接受。未领取的 PENDING/NEEDS_REVIEW 不进入模型历史；领取在数据库 CAS 中绑定真实 Run/Task，移动排队消息到实际投递顺序。withdraw 保留原文并写 WITHDRAWN。编辑/重试截断旧历史保留未领取输入；清空/删除会话仍沿明确的删除操作。

STEER 是当前任务的补充，检查 Task 与停止代次；QUEUE 是后续独立请求，不把多个任务的输入拼成一条消息。失败、取消和清理属于该请求，后续排队失败不会覆盖已完成的原请求。程序化输入和语音只携带自己的正文/附件，不读取或清空用户文字草稿。

后台 `prompt(wait=false)` 在 Room 接收后返回 Accepted 或 Running，并返回精确用户消息 ID；稳定 requestId 重试不重复执行。进程重建将 RUNNING 标为 INTERRUPTED，不自动重放动作。未领取的人类 QUEUE 保留；旧 STEER、程序化及备份输入要求重新选择投递方式，不能从例程权限档自动变成普通聊天执行。

## 核验、成果与备份

核验精确 execution/Run/Task，Room 提交证据后才 ACK。完整非 append 文件按原意图大小/哈希核验；后台 Job/子代理须有精确身份与确定终态。超时、被杀、原生迟到或不确定结果保留 UNKNOWN。用户“不确定”“部分生效”、跳过或问答取消不结算动作。核验不隐式完成目标或恢复等待/暂停任务。

原生现场核验覆盖已停止任务和无 nonce 的 legacy 记录，legacy ACK 使用完整记录摘要，不能按可重用 call ID 批量删除。敏感成功回执可以证明真实执行，但验收证据只保存身份及 `output_redacted`，不保存敏感正文或其内容哈希。

SAF 证据保持 content document URI；Android 26–28 无法使用公开 API 确认嵌套树关系时拒绝核验，可使用精确文档的持久授权；重新核对持久 read grant 和 DocumentsContract 树内关系，拒绝目录，双次流式大小/SHA 核验及撤权失败关闭。导出由用户选择目标文档；全员共享是明确操作，复制到 `/shared/tasks/<task>/` 并核对指纹，CAS 追加 deliveries。失败只清理本次未记录的新复制路径；已提交交付证据的复制保持。原始文件和历史验收事实不被交付失败改写。

成员背景从自身最近已完成任务推导；其它成员只发现用户明确 `global_shared` 的交付引用，不披露其私有原始目标/会话正文。历史指纹不代表当前可访问，打开/导出前仍核验。

CHATS 备份保存任务和关联未知 sidecars，计入 manifest 计量。导入不覆盖现役同 ID 任务；非终态任务恢复为 PAUSED，保留预算、计划与原执行身份。sidecar 导入完整后才开放现场复核；原生复核不清除 UNKNOWN，不派发旧命令或委派。Task 仍须显式恢复，使用计数不归零；导入输入先审查。

## 协作与声音

子代理持久保存 parent Task/Run/revision/stopGeneration/execution；接受与终态分开。仍在运行的关联子工作不能验收根任务。终态回执由负责人检查；稳定投递身份防止重复启动复盘。原任务停止、修改或后来切换其它任务时，结果只保留为回执，不唤醒旧工作。进度报告不启动新的模型回合。

取消按 Task ID 停止关联 Shell Jobs/子代理；暂停保留已运行成员的工作，但停止旧代次负责人继续派发。child 取消针对原请求身份，不能取消同一 child 会话后来进入的用户请求。Ralph 在原共享 stateDir 原子保存不可变目标、round 预算/交接和真实父子关联；每轮启动前检查原任务仍允许继续。

例程沿原 JSON 存储和 READ_ONLY/FULL 档，背景所有者维持权限直到请求清理。立即运行收到持久接收后才报告启动；CLI 分开返回接受、完成和失败事实。

唤醒恢复最近语音会话时再次核对原成员身份和 enabled 状态；失效时使用用户明确选定的默认接待成员或普通草稿。显式 Task 选择只影响用户追问，不覆盖程序化派工身份；历史/暂停目标可只读询问状态，不隐式恢复。聊天和语音显示同一 Task 阶段、等待原因和成果入口。录音、播报、通话拥有的回合分别控制；挂断仅结束音频等待，已接受任务继续。短简报读取原请求 Run 的真实结果，不把一次回复结束称为目标完成。
