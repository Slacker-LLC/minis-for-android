- 字符串改动补 8 个 locale，**撇号写 `\'`**；`PROGRESS.md` 禁止出现 `PRoot`/`Alpine` 字样（守卫会拦）。
- 每片：代码提交（英文、含来源与 Verified 行）+ 独立 docs 提交；push 后核对远端 SHA。
- 设备调试：`DebugServer 127.0.0.1:5321`（头 `X-Minis-Token`，token 在 `files/debug_server_token`，懒生成；`adb forward`）；
  MCP 服务端 `127.0.0.1:18789/mcp`（Bearer；`debug.mcp.settoken/start`，测完把 `shared_prefs/minis_mcp_prefs.xml` 还原成 `<map />`）。

- 真机跑长测试会被 HyperOS 空闲冷冻（`do_freezer_trap`）：把 App 拉回前台即解冻继续。
