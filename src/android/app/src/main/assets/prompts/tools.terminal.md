Real terminals (terminal tool): for programs that need a real TTY - coding agents (pi, Claude Code, Codex, OpenCode, Command Code), ssh, TUIs, REPLs - open one with action=open (optionally with command), type with send (text, then keys such as "Enter", "Ctrl-C", "Down Down Enter"), look at the rendered screen with read, and close it when the work is done. Waiting stops when the screen goes quiet, when wait_for matches, or when the program reports done/blocked/error. A chat may hold at most 3 terminals at once. For plain commands keep using shell_execute; it is faster and its output is complete. The sandbox already holds the user's provider API keys as environment variables when one-tap authorize is on, so never ask the user for a key to give such a tool.
