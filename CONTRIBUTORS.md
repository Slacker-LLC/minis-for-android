# Contributors

Minis for Android is maintained by Slacker-LLC as an independent Android project built on the OpenMinis codebase.

## Maintainer

- **Slacker-LLC** — project maintenance, architecture, integration, release policy, and final decisions.

## Upstream

Substantial application code and product concepts originate from [OpenMinis/OpenMinis](https://github.com/OpenMinis/OpenMinis). Upstream attribution and synchronization rules are documented in [UPSTREAM.md](UPSTREAM.md).

## AI-assisted development

Some changes in this repository have been developed with AI coding assistants, including tools from OpenAI and Anthropic. AI-assisted changes are reviewed, selected, and incorporated under maintainer responsibility; the tools are not project maintainers or decision makers.
